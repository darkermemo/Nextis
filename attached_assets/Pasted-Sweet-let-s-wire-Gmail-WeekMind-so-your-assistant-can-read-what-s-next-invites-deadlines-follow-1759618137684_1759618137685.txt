Sweet—let’s wire Gmail → WeekMind so your assistant can read what’s next (invites, deadlines, follow-ups) and turn them into tasks/events automatically. No Python. This is for Next.js (App Router) + Node/TS using the official Google APIs.

What you’ll get
	•	OAuth sign-in with Google

5) Routes (Next.js App Router)

A) Start OAuth

app/api/gmail/oauth/start/route.ts

import { NextResponse } from "next/server";
import { google } from "googleapis";

export async function GET() {
  const oauth2 = new google.auth.OAuth2(
    process.env.GOOGLE_CLIENT_ID!,
    process.env.GOOGLE_CLIENT_SECRET!,
    process.env.GOOGLE_REDIRECT_URI!
  );
  const url = oauth2.generateAuthUrl({
    access_type: "offline",
    prompt: "consent",
    scope: ["https://www.googleapis.com/auth/gmail.readonly"]
  });
  return NextResponse.redirect(url);
}

7) What to parse into “What’s next”

A) Calendar invitations / events

Patterns:
	•	Content-Type: text/calendar (.ics)
	•	Subject contains: “Invitation”, “Event”, “Meeting”, “RSVP”
	•	From known calendar services (Google Calendar, Microsoft, Calendly, Zoom)

Action:
	•	Extract title, start/end, location/Zoom, organizer → create event (fixed), D-2 & T-5h reminders, add prep checklist (agenda, materials).

B) Deadlines & action requests

Queries you can run (Gmail search syntax) to find candidates:
	•	subject:(deadline OR due OR submit) newer_than:7d
	•	in:inbox (action required OR follow up OR reply) newer_than:7d
	•	has:userlabels (if you auto-label with filters)

Action:
	•	Create tasks with due inferred from subject/body (use LLM only to extract dates/titles into JSON).
	•	If unclear → create task with “Needs date” and notify for confirmation.

C) PRs / code reviews (GitHub mails)
	•	Subjects like [repo] Pull Request #123 or “Review requested”
Action:
	•	Create a 30–45m review block next high-success window; add link to PR.

D) Travel & tickets (optional)
	•	“Your flight,” “Booking,” “Reservation”
Action:
	•	Create fixed events + travel buffers; warn if conflicts.

8) Mapping to your data model

Create Items:
	•	type: event | task
	•	fixed: true for event
	•	title: from subject/ICS
	•	start/end: for events; deadline for tasks
	•	reminders: [D-2, T-5h] (events), [day-before, same-day] (tasks)
	•	tags: ["gmail","invite"] / ["gmail","deadline"]
	•	notes: thread link (https://mail.google.com/mail/u/0/#inbox/THREAD_ID)
